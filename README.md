SOCIAL NETWORK ANALYZER(DSA Project)

Description :
This Project simulates a social network using Graph data structure.
Users are represented as nodes and friendships as edges.

Features :
1. Add Users
2. Add Friendships
3. Display Network
4. Validation(no duplicate users or friendships)

Data Structures Used :
1. Graph(Adjacency List)
2. HashMap(unordered_map)

How to Run :
1. Compile the code : g++ main.cpp -o app
2. Run: ./app

Future Improvements 
1. Friend Recommendation using BFS
2. Mutual Friends
3. Shortest path between Users
